# Bitrix24 Data Processing Agreement — Status

> **⚠️ TEMPLATE — Legal review required.**

## Current Status: NOT APPLICABLE

Since Bitrix24 Enterprise On-Premise is deployed on **JOL's own Proxmox
infrastructure**, the traditional DPA between separate controller and processor
entities does not apply in the standard sense.

**Rationale:**
- JOL is both the data controller and the operator of the Bitrix24 instance.
- Bitrix24 software runs entirely within JOL-controlled infrastructure.
- No data leaves JOL's EU infrastructure to reach a Bitrix24-operated server.
- Bitrix24 as a software vendor does not process JOL's data.
